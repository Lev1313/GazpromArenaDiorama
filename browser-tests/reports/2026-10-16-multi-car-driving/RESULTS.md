# Stage 7C — все 18 автомобилей управляемы

Основа: `origin/master` `e7dcf3e`, объединённый PR #5. Ветка: `feature/multi-car-driving`. ROADMAP.md, исходные GLB, пользовательский CONTEXT исходного worktree, ZIP и резервный Lexus GLB сохранены. Новая модель GLA не добавлялась.

## Результат

`vehicleDrive.js` содержит один контроллер выбранной машины. Посадка на водительское место любой записи registry запускает его; пассажирское место управления не даёт. Серебристый и красный Golf имеют разные ID, корневые объекты и настройки. Физическая высадка сохраняет позицию/yaw, повторная посадка продолжает поездку. Legacy Golf использует отдельный путь входа через совместимый адаптер. R сбрасывает выбранную машину только при свободном домашнем месте.

Коллизии используют live-footprint, yaw и высоту выбранной машины. Для GL захватывается более высокий контур статических препятствий. Трафик и дрифтеры учитывают перемещённые машины после высадки. Точки дыма/следов масштабируются по габариту; один существующий проектор фар переносится между корнями. Исходные GLB, материалы и облегчённая теневая форма Lexus не менялись.

## Проверки и метод

- `npm.cmd run build`: production bundle; известное предупреждение Vite о размере основного JS chunk. В обычной сборке отсутствуют `__readDiorama`, `__approachSeat` и другие тестовые hooks.
- `npm.cmd run test:unit`: 115/115. В том числе физика после посадки для всех 18 ID, 54 пассажирских места, R для каждого автомобиля, выход на скорости/при заблокированной двери, сохранение предыдущих машин, footprint SUV, удержание газа перед оградой/другой машиной/водой, дым/ручник, перенос фар и уступание трафика/дрифтеров.
- `npm.cmd run test:browser`: **380/380**, полный набор в Edge/SwiftShader, без console/page errors; подробные проверки в `report.json`.
- Каждый из 18 ID проходит реальную цепочку: безопасная начальная точка пешехода у двери → E → W → A → запрет выхода на скорости → Space → E → повторная посадка. Fixture задаёт только старт пешехода; координаты автомобиля в этих проверках не присваиваются. Сверяются скорость, yaw, перемещение, поза персонажа, роль и сохранение всех предыдущих машин. Часть длинных промежутков подавляет GL draw calls для ускорения теста; финальные кадры и скриншоты отрисовываются настоящим WebGL.
- Проверки сцены, старого управления Golf, мобильных педалей, прогулки, дня/ночи, трафика, дрифта и HUD сохранены в полном наборе.
- После поездок: геометрии сцены 1241 → 1241, материалы 378 → 378, текстуры сцены 11 → 11; запросы трёх GLB не повторились. GPU-счётчик загрузки геометрий меняется при первом появлении мешей в кадре, поэтому его начальное значение не используется как проверка утечки.
- `node tools/multi-car-review.mjs`: четыре независимых поездки через E и клавиши, без перестановки автомобиля. Все четыре PNG визуально просмотрены; отчёт поз и скорости — `captures.json`.

## Производительность

`node tools/multi-car-cpu.mjs`: сравнение с `e7dcf3e`, пять чередующихся серий по 10 000 обновлений после 1000 прогревочных кадров. Медиана полного CPU-обновления трафика/дрифта/эффектов при неактивном локальном водителе: 0,03676 мс → 0,03969 мс, разница около 0,00293 мс. Дальний предварительный фильтр сохраняет точные SAT-проверки только для близких машин. Сырые серии — `cpu-report.json`.

Это Node-замер симуляции без рендера и парсинга GLB. Он не измеряет FPS видеокарты, время загрузки через Production или работу физического телефона. Браузерные проверки подтверждают стабильность ресурсов сцены и отсутствие повторных запросов моделей, но не заменяют GPU/memory-профилировщик.

## Ограничения

- Аркадные параметры; масса представлена условной инерцией. Контакт останавливает машину, без импульсов/повреждений.
- Колёса и двери импортированных GLB не анимируются отдельно; персонаж сидит на существующих калиброванных местах.
- Задняя ось GLB для эффектов определяется пропорциями footprint, без заявления о заводской точности.
- Камера сохраняет прежнее отсутствие обхода препятствий: её могут закрывать опоры ЗСД и другие объекты.
- Позиции машин сохраняются в текущей сессии; перезагрузка страницы восстанавливает сцену.
- PR предназначен для review; merge и публикация Production не выполнялись. Одобренные визуальные эталоны не перезаписаны.
