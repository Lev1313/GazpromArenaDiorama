## 2. Технологии

- **Three.js r164** (`REVISION = '164'`) и **OrbitControls** встроены в файл как base64 `data:` URL внутри `<script type="importmap">`. Это примерно 1,74 МБ из 1,79 МБ файла.
- Код приложения — один инлайн `<script type="module">` на ~48 КБ, минифицированный: длинные строки, однобуквенные хелперы.
- Внешних ассетов нет. Все текстуры создаются процедурно через `<canvas>`: зерно асфальта, вывески, подписи-спрайты, дым.
- Отдельный классический `<script>` ловит `window.error` и показывает сообщение в `#err`.
- CSS инлайн, есть адаптив: `max-width:640px` и `pointer:coarse` для сенсорных педалей.
- Сборщика, `package.json` и зависимостей нет.

## 3. Как запустить локально (проверено)

Файл самодостаточный. Оба способа проверены в headless Edge (SwiftShader WebGL), сцена отрисовывается одинаково:

1. **Двойной клик / `file://`.** Работает, потому что модули встроены как `data:` URL.
2. **Локальный сервер (рекомендуется):**
   ```powershell
   py -m http.server 8765 --bind 127.0.0.1
   # открыть http://127.0.0.1:8765/gazprom_arena_diorama.html
   ```

Окружение этой машины: Python 3.13 (`py`), Edge и Chrome установлены. **Node.js/npm не установлены.** Для перехода на Vite нужен Node.js LTS (≥ 20.19 или ≥ 22.12 для Vite 7).

## 6. Замечания аудита (не исправлялись)

1. ~~Пустые AGENTS.md / CONTEXT.md с расширением `.txt`.~~ Решено: пользователь заполнил файлы, они переименованы в `.md`.
2. **Нет начального коммита.** Перед рефакторингом стоит зафиксировать оригинал, чтобы было с чем сравнивать.
3. **Порядок построения важен:** `batchArchitecture()` сливает всё, что лежит в `scene` на момент вызова. Машины, люди, дым и следы создаются **после** батчинга, поэтому остаются отдельными объектами. Материалы машин уникальны, потому что `shareStaticMaterials = false`, — на этом держится `parked[5]...color.set(...)` для Golf. В модульной версии этот порядок нужно сделать явным.
4. **Неконсистентность День/Ночь:** при старте `hemi.intensity = 1.8`, а после возврата в «Ночь» становится `2`. Возможно, это баг; решать при переносе только по согласованию.
5. **16 `PointLight`** в forward-рендере MeshStandardMaterial — основная нагрузка на шейдеры. Кандидат на оптимизацию позже, но не в рамках переноса.
6. Примитивы пишут в глобальную `scene`, `line()` не отбрасывает тень (в отличие от `cube`/`cyl`) — поведение нужно сохранить.
7. `place()` и `highwayPoint()` создают новые `Vector3` каждый кадр — мелкий GC-шум, не критично.
8. Подпись «СЕВЕР ↑» и ориентация «север = −Z» — единственная документация системы координат.
9. Обработчик `window.error` ловит **любую** ошибку, не только WebGL. Текст может вводить в заблуждение.

## 7. План перехода на модульную архитектуру Three.js + Vite

### Принципы
- **Перенос без изменения поведения:** сначала 1:1, улучшения — отдельными шагами потом.
- Three.js закрепить на **`three@0.164.x`**, чтобы картинка совпадала (освещение и цветовые пространства между версиями меняются). Обновление — отдельный этап.
- Все координаты и геометрические константы переносятся без изменений в один модуль.
- После каждого этапа — визуальная сверка с эталонными скриншотами.

### Целевая структура
```
index.html                 # разметка HUD без инлайн-скриптов и стилей
package.json, vite.config.js
public/                    # (пока пусто — ассетов нет)
legacy/gazprom_arena_diorama.html   # оригинал как эталон
src/
  main.js                  # сборка приложения, порядок инициализации
  styles/main.css
  core/      renderer.js  camera.js (camera+OrbitControls)  lights.js  loop.js
  config/    geography.js (island, mainland, lotOutline, arenaX, highway points, Lakhta pos)
             cameraPresets.js  palette.js
  materials/ materials.js (mat + кэш + флаг шаринга)  textures.js (асфальт, дым)
  utils/     primitives.js (cube/cyl/line/polygon с параметром parent)  signs.js (surfaceSign/label)
  world/     terrain.js  parking.js  arena.js  highway.js  lakhta.js  vegetation.js
             lamps.js  streetProps.js  labels.js  batching.js
  entities/  car.js  person.js
  sim/       traffic.js (ЗСД + визитёры)  drift.js  skids.js  smoke.js
  drive/     input.js  collisions.js  golfPhysics.js  driveCamera.js  driveMode.js
  ui/        hud.js (кнопки, статистика, день/ночь, пауза, темп)
```
